NANDbox

Getting Started

  • Add Parts In EDIT mode, drag components from the side panel onto the canvas
  • Connect Click a connector (circle), then click another — a wire is created
  • Interact Click buttons/switches to toggle, click clock to pause/resume
  • Move Drag a component's body to reposition it on the canvas

Side Panel

  • Collapsing Click any category header to collapse/expand that section
  • Adding While in EDIT mode, drag components from the side panel to the workspace
  • Activating While in EDIT mode, click input components to activate them

Toolbar

Pan — Enables workspace panning and scrolling. Circuit interaction disabled
Edit — Enables circuit editing, wiring, dragging, and interaction
Delete All — Deletes the entire circuit after confirmation
Help — Opens this help page
Settings — Simulation speed, canvas theme, grid toggle
  • 💾 Export Downloads the current circuit as a .nandbox.json file
  • 📂 Import Loads a previously exported circuit from a JSON file
  • 📚 Library Opens the pre-made circuit library (SR Latch, Half Adder, etc.)

Mouse Controls

  • Panning While in PAN mode, click and drag to pan the circuit
  • Zooming While in PAN mode, scroll to zoom in and out
  • Inputs While in EDIT mode, click input components to activate them
  • Wiring In EDIT mode, click two connectors to wire them. Invalid connections are rejected
  • Selecting Double-click a component to select it for deletion
  • Multi-Select In EDIT mode, drag on empty canvas to draw a selection box
  • Group Drag When dragging a selected component, all selected components move together
  • Repositioning Drag any component's body to move it. Wires follow automatically
  • Gate Delays Right-click any gate to set individual input/output delay (in ticks)

Keyboard Shortcuts

  • Delete / ⌫ Delete selected component(s) and their wires
  • Ctrl+Click Hold Ctrl to keep existing selections when clicking

Components

  • Button Momentary input — HIGH only while held
  • Switch Toggle input — click to flip between HIGH and LOW
  • VCC / GND Constant HIGH (1) and LOW (0) sources
  • Clock Auto-toggling input. Click to pause/resume. Drives flip-flop clock inputs
  • LED Visual output — lights up red when HIGH, gray when LOW
  • 7-Segment 4-bit BCD display — shows digits 0–F
  • Label Text annotation — double-click to edit text

Gates

  • NOT Inverts input: 0→1, 1→0
  • AND Output HIGH only when both inputs HIGH
  • OR Output HIGH when either input HIGH
  • NAND Inverted AND — LOW only when both inputs HIGH
  • NOR Inverted OR — HIGH only when both inputs LOW
  • XOR Output HIGH when inputs differ
  • XNOR Output HIGH when inputs match

Flip-Flops

  • T Flip-Flop On rising clock edge: T=1 toggles Q, T=0 holds Q
  • JK Flip-Flop On rising clock edge: J=1,K=0 sets; J=0,K=1 resets; J=K=1 toggles; J=K=0 holds

Settings

  • Sim Speed Adjustable from 1 to 120 ticks/second (default: 60)
  • Theme Light (default), Dark, or Blueprint canvas background
  • Grid Toggle the canvas grid on/off — grid scales with zoom

Status Bar

  • Zoom Current zoom level displayed as percentage (bottom-left)
  • Coordinates Real-time cursor position on the canvas (X, Y)

Signal Colors

  • ● Red HIGH signal (logic 1)
  • ● Gray LOW signal (logic 0)
  • ● Green Floating / unconnected
